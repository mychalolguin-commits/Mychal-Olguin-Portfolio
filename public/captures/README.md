# Platform captures

Drop your real platform screenshots in this folder. The site looks for these
exact filenames and swaps them in automatically — no code change needed.

| Filename | What it should show | Appears on |
|---|---|---|
| `ga4-overview.png` | GA4 acquisition or landing-page report for the Towne Oaks window | Homepage, below the headline |
| `search-console.png` | Search Console clicks + impressions trend | Homepage, tracking section |
| `meta-ads-manager.png` | Meta Ads Manager campaign table — spend, LP views, cost per LP view | Towne Oaks case study |
| `utm-taxonomy.png` | Your UTM sheet or naming convention (optional) | Towne Oaks case study |

Until a file exists, that slot falls back to a chart rendered from the real
numbers already in `constants.ts`, so the page is never broken or empty.

## Websites I built

These are different from the platform captures above: the screenshot *is* the
work, not a report about the work. Full-page grabs of the live site, top to
bottom.

| Filename | What it should show | Appears on |
|---|---|---|
| `borders-site.png` | Borders homepage, full page | Apartment websites case study |
| `compass-bay-site.png` | Compass Bay homepage, full page | Apartment websites case study |
| `verano-oaks-site.png` | Verano Oaks homepage, full page | Apartment websites case study |
| `apts-ai-answer.png` | ✅ **Landed.** ChatGPT citing Borders' own site for its pet policy | Apartment websites case study |
| `apts-ai-answer-full.png` | ✅ **Landed.** The same answer including the map and the query | Apartment websites case study |
| `apts-schema.png` | Rich Results Test or the schema block on a live page | Apartment websites case study |

**Do not blur these.** The redaction rule above exists because a client's
account numbers aren't the point. Here the opposite is true: these are public
marketing sites you designed and shipped, and naming them is the credential.
The property name stays.

`apts-ai-answer.png` is the proof for the AI-search argument and it is already
here. In that answer, seven Brownsville properties are listed; only two are
cited from their own website rather than from Rent.com, Realtor, or
Apartments.com — and Borders is one of them. The line ChatGPT quotes is the
pet policy, which is page content, not listing-feed data.

Read that citation chip carefully before writing any claim around it. What it
supports: the property's own page was retrieved and quoted. What it does not
support: a ranking, a traffic number, or proof of causation. The site's whole
argument is that the source is shown — so the claim has to stop where the
screenshot stops.

## Before you export

- **Blur or rename anything client-identifying** — property names, account IDs,
  billing details. The numbers are the point; the client's name isn't.
- Export the **widest window you can**. These run edge-to-edge, so bigger is
  better. 2x / retina if your screen supports it.
- PNG. Don't pre-crop them tightly — the site never crops a capture (that would
  let the layout decide which numbers a visitor gets to see), so whatever you
  export is exactly what shows.
- Light mode screenshots sit better on the cream background than dark ones.
